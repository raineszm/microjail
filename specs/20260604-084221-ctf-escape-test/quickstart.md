## 1. Overview of What Changes

The CTF escape-test runner (`ctf/`) is a **standalone Python package at the repo root**
that verifies microjail containment by running an adversarial agent loop inside an
ephemeral Workshop environment. It is *not* a sub-package of `microjail`; it shares the
same venv and may import from `microjail.*`, but the reverse is prohibited.

### What is new

| File | Role |
|------|------|
| `ctf/__init__.py` | Namespace package; `__all__ = ["main"]` |
| `ctf/__main__.py` | `python -m ctf` entry point → `app()` |
| `ctf/main.py` | typer CLI + full test lifecycle |
| `ctf/models.py` | `Secret`, `TestRunConfig`, `TestRun` dataclasses |
| `ctf/secrets_gen.py` | `generate_secrets()` |
| `ctf/http_server.py` | `HostHttpServer` + `start_http_server()` |
| `ctf/workshop_config.py` | `generate_ctf_workshop_yaml()` + `generate_inference_sdk_yaml()` |
| `ctf/report.py` | `ContainmentReport`, `print_report()`, `write_report()` |
| `ctf/agent_script.sh` | Copied verbatim into workspace; executed inside container |

### What is unchanged

`src/microjail/commands/init.py`, `src/microjail/config/workshop.py`, and the gate
infrastructure are **not modified** by this feature. The CTF runner bypasses `microjail
init` entirely (FR-004) because it needs `omp`, not `opencode+skills`.

The `workshop_client.connect()` function in `src/microjail/workshop/client.py` was
**added** as part of this feature; it is used only by `ctf/main.py`.

## 2. New API: `ctf/workshop_config.py`

### Why two YAML files instead of one

The existing `generate_workshop_yaml` in `src/microjail/config/workshop.py` embeds the
inference plug inline inside the workshop YAML:

```yaml
# microjail/config/workshop.py — current (inline plug, no connect step)
sdks:
  - name: llama-cpp
    plugs:
      llama-cpp:
        interface: tunnel
  - name: system
    slots:
      llama-cpp:
        interface: tunnel
        endpoint: "localhost:8080"
```

Workshop requires a separate `sdk.yaml` file for project-local SDKs and an explicit
`workshop connect` call to wire them. The CTF runner splits this into two files:

```
<workspace>/
  .workshop/
    <env_name>.yaml          ← workshop environment definition (generated by generate_ctf_workshop_yaml)
    local-inference/
      sdk.yaml               ← project SDK definition (generated by generate_inference_sdk_yaml)
```

### `generate_ctf_workshop_yaml(env_name, inference_host, inference_port) → str`

References the project SDK by name (`project-local-inference`); the actual plug lives in
`sdk.yaml`, not inline:

```python
from ctf.workshop_config import generate_ctf_workshop_yaml

yaml_str = generate_ctf_workshop_yaml("ctf-1a2b3c4d", "192.168.1.5", 8080)
```

Produces:

```yaml
name: ctf-1a2b3c4d
base: ubuntu@24.04
sdks:
  - name: omp
    channel: 14/edge
  - name: project-local-inference   # reference to .workshop/local-inference/sdk.yaml
  - name: system
    slots:
      llama:
        interface: tunnel
        endpoint: "192.168.1.5:8080"
```

Key differences from `generate_workshop_yaml`:
- `omp` instead of `opencode` + `skills`
- `project-local-inference` reference (no inline `plugs:` block)
- Slot name is `llama` (not `llama-cpp`)
- `endpoint` is the real host address, not `localhost:8080`

### `generate_inference_sdk_yaml(inference_port) → str`

Generates the project SDK that declares the plug:

```python
from ctf.workshop_config import generate_inference_sdk_yaml

sdk_str = generate_inference_sdk_yaml(8080)
```

Produces:

```yaml
name: local-inference
plugs:
  llama:
    interface: tunnel
    endpoint: "localhost:8080"
```

The `endpoint` here is the **host-side** address: `localhost:<port>`. Workshop uses this to
establish the TCP tunnel into the container.

### `INFERENCE_PLUG_REF` / `INFERENCE_SLOT_REF` (planned constants)

`ctf/main.py` currently uses string literals for the `workshop connect` arguments:

```python
workshop_client.connect(
    env_name, "local-inference:llama", "system:llama", workspace
)
```

These should be extracted as module-level constants in `ctf/workshop_config.py` so the
connect call and the YAML generator stay in sync when names change:

```python
# ctf/workshop_config.py
INFERENCE_PLUG_REF: str = "local-inference:llama"   # <sdk-dir>:<plug-name>
INFERENCE_SLOT_REF: str = "system:llama"            # system:<slot-name>
```

Then in `ctf/main.py`:

```python
from ctf.workshop_config import (
    INFERENCE_PLUG_REF,
    INFERENCE_SLOT_REF,
    generate_ctf_workshop_yaml,
    generate_inference_sdk_yaml,
)

workshop_client.connect(env_name, INFERENCE_PLUG_REF, INFERENCE_SLOT_REF, workspace)
```

The invariant is: `INFERENCE_PLUG_REF` must use the same SDK directory name as the
`project-{name}` entry in `generate_ctf_workshop_yaml`, and the same interface name as
the `plugs:` key in `generate_inference_sdk_yaml`.

## 3. How the CTF Init Flow Works (Phase 1 of `ctf/main.py`)

`microjail init` does: validate → write workshop.yaml → launch → write state.json.

The CTF runner does more, and in a different order:

```
1.  generate_secrets()                          → (fs_secret, net_secret)
2.  tempfile.mkdtemp(prefix="microjail-ctf-")  → workspace
3.  env_name = "ctf-" + secrets.token_hex(4)
4.  shutil.copy(agent_script.sh, workspace/)
5.  write .workshop/<env_name>.yaml             ← generate_ctf_workshop_yaml()
6.  mkdir .workshop/local-inference/
7.  write .workshop/local-inference/sdk.yaml    ← generate_inference_sdk_yaml()  [NEW]
8.  workshop_client.launch(env_name, workspace)
9.  workshop_client.verify_exists(env_name, workspace)
10. workshop_client.connect(                                                      [NEW]
        env_name, INFERENCE_PLUG_REF, INFERENCE_SLOT_REF, workspace
    )
11. _probe_inference_tunnel(env_name, workspace, port, shutdown)                  [NEW]
12. write /tmp/ctf-secret-<uuid>               ← filesystem secret
13. start_http_server(net_secret, port=port)   → server, actual_http_port
14. write ctf_prompt.txt                       ← prompt with substituted values
15. mkdir .microjail/
16. write .microjail/state.json                ← minimal state required by lock_egress
17. construct TestRunConfig + TestRun
```

Steps 6–11 have no equivalent in `microjail init`. The connect + probe steps ensure the
tunnel is wired and working before the agent loop starts; if either fails the runner aborts
and cleanup runs.

### The `sdk.yaml` write (step 7)

```python
sdk_dir = workshop_dir / "local-inference"
sdk_dir.mkdir(exist_ok=True)
(sdk_dir / "sdk.yaml").write_text(generate_inference_sdk_yaml(inference_port))
```

### The connect step (step 10)

```python
workshop_client.connect(
    env_name, "local-inference:llama", "system:llama", workspace
)
```

`workshop_client.connect` wraps:

```
workshop --project <workspace> connect <env>/<plug_ref> <env>/<slot_ref>
```

This is a blocking call; it raises `RuntimeError` on non-zero exit.

### The tunnel probe (step 11)

Retries `bash -c "echo >/dev/tcp/localhost/<port>"` inside the container up to 10 times
at 3-second intervals. Raises `RuntimeError` if the endpoint is still unreachable after
all retries. The probe runs before secrets are planted so a misconfigured tunnel causes
an early, clean abort rather than a silent dead run.

### The `state.json` write (step 16)

`lock_egress` reads `workspace/.microjail/state.json` to derive bind-mount paths. The
runner writes the minimal required fields directly; it does not go through `microjail init`:

```python
_STATE_JSON_TEMPLATE: dict[str, object] = {
    "base_image": "ubuntu@26.04",
    "inference": "llama-cpp",
    "agent": None,          # ← None: omp is not tracked via the agent field
    "socket_url": "http://localhost:8080/v1",
    "locked": False,
}
```

`agent: None` is intentional — `omp` is not managed through the `--agent opencode`
codepath and should not be.

## 4. How `ctf/main.py` Changed

### Imports

```python
from ctf.workshop_config import generate_ctf_workshop_yaml, generate_inference_sdk_yaml
from microjail.lxd.network import lock_egress, unlock_egress
from microjail.workshop import client as workshop_client
```

The CTF runner imports directly from `microjail.lxd.network` and `microjail.workshop`
rather than shelling out to the `microjail` CLI. This avoids duplicating LXD logic.

### Workshop config (Phase 1)

Two files are written instead of one:

```python
# workshop.yaml
workshop_dir = workspace / ".workshop"
workshop_dir.mkdir(parents=True, exist_ok=True)
(workshop_dir / f"{env_name}.yaml").write_text(
    generate_ctf_workshop_yaml(env_name, inference_host, inference_port)
)

# sdk.yaml for the project SDK
sdk_dir = workshop_dir / "local-inference"
sdk_dir.mkdir(exist_ok=True)
(sdk_dir / "sdk.yaml").write_text(generate_inference_sdk_yaml(inference_port))
```

### State (Phase 1)

```python
microjail_dir = workspace / ".microjail"
microjail_dir.mkdir(parents=True, exist_ok=True)
state_doc = {
    **_STATE_JSON_TEMPLATE,
    "name": env_name,
    "created_at": datetime.now(UTC).isoformat(),
}
(microjail_dir / "state.json").write_text(json.dumps(state_doc, indent=2))
```

### Connect (Phase 1)

After `verify_exists`, before planting secrets:

```python
workshop_client.connect(
    env_name, "local-inference:llama", "system:llama", workspace
)
_probe_inference_tunnel(env_name, workspace, inference_port, shutdown)
```

If `connect` or the probe raises, the `except` block sets `outcome = "error"` and the
`finally` block runs cleanup.

### Full Phase 1 sequence in context

```python
try:
    fs_secret, net_secret = generate_secrets()
    workspace = Path(tempfile.mkdtemp(prefix="microjail-ctf-"))
    env_name = "ctf-" + _secrets.token_hex(4)
    tmp_secret_path = Path(f"/tmp/ctf-secret-{uuid.uuid4().hex}")

    shutil.copy(_AGENT_SCRIPT_SRC, workspace / "agent_script.sh")

    workshop_dir = workspace / ".workshop"
    workshop_dir.mkdir(parents=True, exist_ok=True)
    (workshop_dir / f"{env_name}.yaml").write_text(
        generate_ctf_workshop_yaml(env_name, inference_host, inference_port)
    )
    sdk_dir = workshop_dir / "local-inference"
    sdk_dir.mkdir(exist_ok=True)
    (sdk_dir / "sdk.yaml").write_text(generate_inference_sdk_yaml(inference_port))

    workshop_client.launch(env_name, workspace)
    workshop_client.verify_exists(env_name, workspace)
    workshop_client.connect(
        env_name, "local-inference:llama", "system:llama", workspace
    )
    _probe_inference_tunnel(env_name, workspace, inference_port, shutdown)
    # ... plant secrets, start HTTP server, write state.json ...
```

## 5. Gate Narrowing: `config-readonly`

`run_all_gates` in `src/microjail/gates/__init__.py` conditionally applies
`check_config_readonly` only when `state.agent is not None`:

```python
# src/microjail/gates/__init__.py
if state.agent is not None:
    results.append(check_config_readonly(workspace))
```

The CTF runner writes `"agent": null` into `state.json`. This means:

- `check_config_readonly` is **skipped** for CTF environments — `opencode.jsonc` is never
  written, and checking for it would always fail.
- `check_inference_tunnel` is still run (because `state.inference == "llama-cpp"`).

If you add a new gate that should apply only to agent-bearing environments, mirror this
pattern:

```python
if state.agent is not None:
    results.append(your_new_gate(workspace))
```

Do **not** check for `opencode.jsonc` in a gate that unconditionally applies — the CTF
environment proves that `agent=None` is a valid production state.

#### Tunnel probe: `tests/unit/test_ctf_main.py`

```python
def test_probe_retries_on_failure_then_succeeds(tmp_path: Path) -> None:
    """Probe retries on non-zero exit; succeeds when a later attempt exits 0."""
    call_count = 0

    def _mock_run(*args, **kwargs):
        nonlocal call_count
        call_count += 1
        rc = 1 if call_count < 3 else 0
        return MagicMock(returncode=rc)

    shutdown = threading.Event()
    with patch("ctf.main.subprocess.run", side_effect=_mock_run):
        _probe_inference_tunnel("myenv", tmp_path, 8080, shutdown)  # must not raise
    assert call_count == 3


def test_probe_raises_after_all_retries(tmp_path: Path) -> None:
    """Probe raises RuntimeError when all retry attempts fail."""
    shutdown = threading.Event()
    with patch("ctf.main.subprocess.run", return_value=MagicMock(returncode=1)):
        with patch("ctf.main.threading.Event.wait"):  # skip sleeps
            with pytest.raises(RuntimeError, match="not reachable"):
                _probe_inference_tunnel("myenv", tmp_path, 8080, shutdown)


def test_probe_raises_immediately_if_shutdown(tmp_path: Path) -> None:
    """Probe raises RuntimeError without completing retries when shutdown is set."""
    shutdown = threading.Event()
    shutdown.set()
    with patch("ctf.main.subprocess.run", return_value=MagicMock(returncode=1)):
        with pytest.raises(RuntimeError, match="Shutdown"):
            _probe_inference_tunnel("myenv", tmp_path, 8080, shutdown)
```
