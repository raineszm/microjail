# Data Model: microjail init Command

**Feature**: `specs/20260529-154152-init-command/`
**Date**: 2026-05-29

## Overview

Three types of data are produced by `microjail init`:

1. **`EnvironmentConfig`** — the in-memory representation of user intent; drives file generation.
2. **`EnvironmentState`** — persisted to `.microjail/state.json`; consumed by downstream commands.
3. **Config file schemas** — the exact structure of `workshop.yaml` and `opencode.jsonc`.

---

## EnvironmentConfig (in-memory, not persisted)

Constructed from CLI arguments at the start of the `init` command. Passed to all generators.

```python
from dataclasses import dataclass
from typing import Literal

InferenceBackend = Literal["llama-cpp"]
AgentHarness = Literal["opencode"]

@dataclass(frozen=True)
class EnvironmentConfig:
    name: str                              # positional <name> argument
    base_image: str                        # "ubuntu@26.04" for P1 (fixed)
    inference: InferenceBackend | None     # None if --inference not passed
    agent: AgentHarness | None            # None if --agent not passed
```

**Constraints**:
- `name`: non-empty string; Workshop environment name rules apply (alphanumeric + hyphens,
  no leading hyphen, max 63 chars — consistent with LXD instance naming).
- `base_image`: fixed at `"ubuntu@26.04"` for P1; field exists to make it configurable in
  a later minor change without touching the generator signatures.
- `inference`: `None` or `"llama-cpp"`. Any other value is rejected at CLI parse time.
- `agent`: `None` or `"opencode"`. Any other value is rejected at CLI parse time.

---

## EnvironmentState (persisted to `.microjail/state.json`)

Written after all config files are generated and after Workshop environment creation is
verified. Read by `microjail run`, `microjail unlock`, and future provisioning commands.

```python
from dataclasses import dataclass
from datetime import datetime

@dataclass
class EnvironmentState:
    name: str                          # Workshop environment name
    base_image: str                    # e.g. "ubuntu@26.04"
    inference: str | None              # "llama-cpp" or null
    agent: str | None                  # "opencode" or null
    socket_url: str | None             # inferred from inference backend; null if no inference
                                       # value is UDS socket path or http loopback — see research.md §3
    created_at: datetime               # UTC ISO-8601 timestamp
```

**JSON representation** (`.microjail/state.json`):

```json
{
    "name": "myproject",
    "base_image": "ubuntu@26.04",
    "inference": "llama-cpp",
    "agent": "opencode",
    "socket_url": "http://127.0.0.1:8080/v1",
    "created_at": "2026-05-29T15:41:52Z"
}
```

For a bare init (no flags):

```json
{
    "name": "myproject",
    "base_image": "ubuntu@26.04",
    "inference": null,
    "agent": null,
    "socket_url": null,
    "created_at": "2026-05-29T15:41:52Z"
}
```

**Storage location**: `<workspace>/.microjail/state.json`
where `<workspace>` is the current working directory at invocation time.

**Lifecycle**:
- Created by `microjail init` after successful Workshop environment creation and verification.
- Read (not modified) by `microjail run` and `microjail unlock`.
- Deleted (or overwritten) when the environment is torn down (future command).

## Workshop definition YAML schema

Generated by `src/microjail/config/workshop.py`. Written to `<workspace>/.workshop/<NAME>.yaml`.

### With `--inference llama-cpp` (and optionally `--agent opencode`)

```yaml
name: myproject
base: ubuntu@26.04
sdks:
  - name: opencode
    channel: latest/stable
  - name: skills
    channel: latest/edge
```

**Fields**:
- `name`: from `EnvironmentConfig.name`.
- `base`: from `EnvironmentConfig.base_image` (`"ubuntu@26.04"` for P1).
- `sdks[0]` (`opencode`): the OpenCode agent harness SDK. Included when `--agent opencode`.
- `sdks[1]` (`skills`): the skills SDK. Included alongside `opencode`.

No `system` SDK. No tunnel plug/slot entries. Inference reaches the container via the UDS
socket file in the bind-mounted workspace directory — no Workshop tunnel is required.

### Without agent (bare or inference-only)

```yaml
name: myproject
base: ubuntu@26.04
sdks: []
```

No SDKs are declared; Workshop creates a plain Ubuntu 26.04 container.

## opencode.jsonc Schema

Generated by `src/microjail/config/opencode.py`. Written to `<workspace>/opencode.jsonc`.
Only written when `--agent opencode` is specified.

```json
{
    "$schema": "https://opencode.ai/config.json",
    "provider": {
        "anthropic":      { "enabled": false },
        "openai":         { "enabled": false },
        "google":         { "enabled": false },
        "amazon-bedrock": { "enabled": false },
        "azure":          { "enabled": false },
        "groq":           { "enabled": false },
        "mistral":        { "enabled": false },
        "xai":            { "enabled": false },
        "deepseek":       { "enabled": false },
        "cerebras":       { "enabled": false },
        "llama.cpp": {
            "name": "llama-server (local)",
            "options": {
                "baseURL": "<uds-path-or-http-loopback>"
            },
            "models": {}
        }
    },
    "plugin": [
        "context-mode",
        "cc-safety-net"
    ]
}
```

**Fields**:
- `$schema`: fixed URL to OpenCode's config schema for editor tooling.
- `provider.<id>.enabled: false`: explicitly disables each known built-in provider.
- `provider.llama.cpp`: the active local inference provider. No `npm` field — uses OpenCode's
  built-in provider mechanism. No ai-sdk package installation is required.
  - `options.baseURL`: the inference endpoint. Value is the UDS socket path or
    `http://127.0.0.1:8080/v1` (socat loopback) — confirmed during implementation.
- `plugin`: fixed list; `context-mode` and `cc-safety-net` are always enabled.

**Note on `baseURL`**: The exact value is determined during implementation (see research.md §3).
The generator function accepts `socket_url: str` as a parameter, so the value can be set at
generation time without changing the schema.

## State Transitions

```
[not initialised]
      │
      ▼  microjail init
[initialised]  ←─── files written + environment created + state.json present
      │
      ▼  microjail run (future)
[locked]       ←─── network egress severed + gates passed
      │
      ▼  microjail unlock (future)
[initialised]  ←─── egress restored; environment still exists
      │
      ▼  microjail destroy (future)
[not initialised]
```

The `init` command transitions from `[not initialised]` to `[initialised]`. If it fails at
any point, the target state is `[not initialised]` — no files written, no environment created,
or files cleaned up if creation failed after writes.

## Validation Rules

| Field | Rule |
|-------|------|
| `name` | Non-empty; matches `^[a-zA-Z][a-zA-Z0-9-]*$`; max 63 chars (LXD constraint) |
| `base_image` | Non-empty string; format `<distro>@<version>`; validated by Workshop on create |
| `inference` | `None` or one of `{"llama-cpp"}`; enforced by typer `Enum` type |
| `agent` | `None` or one of `{"opencode"}`; enforced by typer `Enum` type |
| `socket_url` | Set to `"http://127.0.0.1:8080/v1"` when `inference == "llama-cpp"`; else `None` |
| `created_at` | UTC datetime; always set by `init`; ISO-8601 format in JSON |
