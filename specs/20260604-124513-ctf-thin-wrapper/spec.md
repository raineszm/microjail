# Feature Specification: CTF Thin Wrapper

**Feature Branch**: `20260604-124513-ctf-thin-wrapper`

**Created**: 2026-06-04

**Status**: Draft

**Input**: User description: "There is a lot of duplication of effort between ctf/main.py and the main microjail command. The test should be as thin a wrapper as possible around microjails commands. Anything that needs to be modified or moved into microjail as a feature flag should be done"

## Clarifications

### Session 2026-06-04

- Q: Should workshop connect be part of microjail init? -> A: Yes, added to init post-launch when inference is not None; CTF retains its `workshop_client.connect()` call but replaces the hardcoded string literals with shared constants from `microjail.config.workshop`.
- Q: How should sdk.yaml generation be exposed? -> A: Separate `generate_sdk_yaml(config)` function alongside `generate_workshop_yaml`.
- Q: Do all inference configs migrate to project-SDK? -> A: Yes, all paths including opencode+llama-cpp.
- Q: SDK directory and plug/slot naming? -> A: Adopt CTF names: directory `local-inference`, plug/slot `llama`.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - CTF uses microjail's environment setup (Priority: P1)

When running the CTF escape test, the setup phase — creating the workshop environment, generating its YAML definition, and persisting state — delegates entirely to microjail's existing config and state machinery rather than duplicating it inline.

**Why this priority**: This is the largest block of duplication. `ctf/main.py` manually writes a state dict and generates workshop YAML that is nearly identical to what `microjail init` already produces. Eliminating this duplication is the primary goal.

**Independent Test**: Run `ctf` with a valid inference URL. Verify that a `.microjail/state.json` is present in the temp workspace with fields matching `EnvironmentState`, and that the workshop YAML was generated by the same code path microjail uses.

**Acceptance Scenarios**:

1. **Given** the CTF runner starts, **When** it builds the workshop YAML for the temp environment, **Then** it calls `generate_workshop_yaml(EnvironmentConfig(...))` from `microjail.config.workshop` — not a CTF-local generator.
2. **Given** setup completes, **When** the state file is written, **Then** `EnvironmentState.to_json()` is called — not a raw `json.dumps` of a hand-built dict.
3. **Given** the workshop YAML is written, **Then** the CTF-specific `generate_ctf_workshop_yaml` and `generate_inference_sdk_yaml` functions no longer exist.

---

### User Story 2 - microjail supports `omp` as an agent type (Priority: P2)

`microjail init` and the underlying config machinery recognise `omp` as a valid agent harness alongside `opencode`. The workshop YAML generator emits the correct `omp` SDK entry (channel `14/edge`; no `skills` SDK) when `agent="omp"` is selected.

**Why this priority**: The CTF environment uses the `omp` agent. Without this flag, CTF cannot use microjail's config generator and must maintain its own divergent copy.

**Independent Test**: Call `generate_workshop_yaml(EnvironmentConfig(name="x", base_image="ubuntu@24.04", inference="llama-cpp", agent="omp"))` and assert the resulting YAML contains `name: omp` with `channel: 14/edge` and no `skills` entry.

**Acceptance Scenarios**:

1. **Given** `EnvironmentConfig(agent="omp")`, **When** `generate_workshop_yaml` is called, **Then** the output contains `name: omp` and `channel: 14/edge` and does not contain `skills`.
2. **Given** `EnvironmentConfig(agent="opencode")`, **When** `generate_workshop_yaml` is called, **Then** the output is unchanged from today (opencode + skills, no omp).
3. **Given** `microjail init myenv --agent omp`, **Then** the CLI accepts the value without error.
4. **Given** `microjail init myenv --agent badvalue`, **Then** the CLI rejects it with an error naming the valid choices.

---

### User Story 3 - microjail supports a configurable inference endpoint (Priority: P2)

The inference tunnel endpoint in workshop YAML generation is configurable rather than hardcoded to `localhost:8080`. CTF passes an arbitrary `host:port` for an external inference server; normal `microjail init` without `--inference-url` defaults to `localhost:8080` as before. Inference is configured via the project-SDK pattern: `workshop.yaml` references a `project-local-inference` SDK entry and `.workshop/local-inference/sdk.yaml` declares the plug.

**Why this priority**: CTF's inference server is on an arbitrary external machine. Without a configurable endpoint, CTF must maintain its own divergent YAML generator.

**Independent Test**: Call `generate_workshop_yaml` with `inference_endpoint="192.168.1.5:8080"` and assert the workshop YAML contains `name: project-local-inference` and the system slot endpoint is `192.168.1.5:8080`. Call `generate_sdk_yaml` with the same config and assert the plug `llama` endpoint is `localhost:8080`.

**Acceptance Scenarios**:

1. **Given** `EnvironmentConfig(inference="llama-cpp", inference_endpoint="192.168.1.5:9000")`, **When** `generate_workshop_yaml` is called, **Then** the workshop YAML contains `name: project-local-inference` (not an inline plug) and the system slot endpoint is `192.168.1.5:9000`; **And** `.workshop/local-inference/sdk.yaml` exists with plug `llama` at endpoint `localhost:9000`.
2. **Given** `EnvironmentConfig(inference="llama-cpp", inference_endpoint=None)`, **When** `generate_workshop_yaml` is called, **Then** the workshop YAML contains `name: project-local-inference` and the system slot endpoint defaults to `localhost:8080`; **And** `.workshop/local-inference/sdk.yaml` exists with plug `llama` at endpoint `localhost:8080`.
3. **Given** `microjail init myenv --inference llama-cpp --inference-url http://192.168.1.5:9000`, **Then** both `workshop.yaml` and `.workshop/local-inference/sdk.yaml` are written to the workspace.

---

### User Story 4 - `check_config_readonly` gate is scoped to opencode only (Priority: P3)

The `config_readonly` lock gate only runs when `agent == "opencode"`. Currently it runs for any non-None agent value, which would fail for `omp` environments that have no `opencode.jsonc`.

**Why this priority**: Required for CTF (and any future non-opencode agent) to use `perform_lock` without a spurious gate failure.

**Independent Test**: Build an `EnvironmentState` with `agent="omp"` and call `run_all_gates`. Assert that `config_readonly` does not appear in the results.

**Acceptance Scenarios**:

1. **Given** `state.agent == "omp"`, **When** `run_all_gates` is called, **Then** no `config_readonly` gate result is returned.
2. **Given** `state.agent == "opencode"`, **When** `run_all_gates` is called, **Then** a `config_readonly` result is returned (existing behaviour preserved).
3. **Given** `state.agent is None`, **When** `run_all_gates` is called, **Then** no `config_readonly` result is returned (existing behaviour preserved).

---

### Edge Cases

- What happens when `inference_endpoint` is provided but `inference` is `None`? The field is ignored; no tunnel is configured.
- What happens when `omp` is passed as `--agent` without `--inference`? The environment is created with the omp SDK but no tunnel — valid and allowed.
- What happens when CTF's temp workspace is cleaned up mid-run? Cleanup path in `ctf/main.py` is unchanged; state.json deletion is still handled by `shutil.rmtree`.
- What happens when `.workshop/local-inference/` already exists when `microjail init --force` runs? Overwrite `sdk.yaml` silently (consistent with `--force` behaviour for workshop YAML).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: `AgentHarness` type MUST include `"omp"` as a valid literal value.
- **FR-002**: `EnvironmentConfig` MUST gain an `inference_endpoint: str | None` field (format `host:port`, default `None`).
- **FR-003**: `generate_workshop_yaml` MUST emit `project-local-inference` as the inference SDK entry (replacing inline plug) when inference is configured; the system slot retains the host-side endpoint (`config.inference_endpoint or "localhost:8080"`).
- **FR-004**: `generate_workshop_yaml` MUST emit `{"name": "omp", "channel": "14/edge"}` for `agent == "omp"` and MUST NOT emit a `skills` SDK entry in this case.
- **FR-005**: `run_all_gates` MUST gate `check_config_readonly` on `state.agent == "opencode"` rather than `state.agent is not None`.
- **FR-006**: `microjail init` MUST accept an optional `--inference-url` flag that sets `inference_endpoint` on the resulting `EnvironmentConfig`.
- **FR-007**: `ctf/main.py` MUST use `generate_workshop_yaml(EnvironmentConfig(...))` to produce the workshop YAML instead of `generate_ctf_workshop_yaml`.
- **FR-008**: `ctf/main.py` MUST use `EnvironmentState(...).to_json(workspace)` to write the state file instead of a hand-built dict.
- **FR-009**: `ctf/workshop_config.py` MUST be deleted after its responsibilities are absorbed into `microjail.config`.
- **FR-010**: `ctf/main.py` MUST replace the hardcoded string literals `"local-inference:llama"` and `"system:llama"` in its `workshop_client.connect()` call with the `INFERENCE_PLUG_REF` and `INFERENCE_SLOT_REF` constants exported from `microjail.config.workshop`.
- **FR-011**: `EnvironmentState.socket_url` for the CTF environment MUST be set to `http://localhost:{inference_port}/v1` (container-side URL), derived from the `--inference-url` argument — not from the hardcoded template value.
- **FR-012**: `generate_sdk_yaml(config)` function MUST be added to `microjail.config.workshop`. Returns sdk.yaml string for the `local-inference` project SDK, declaring a plug named `llama` with `interface=tunnel` and `endpoint=localhost:{inference_port}`. Returns empty string when `inference` is `None`. Port extracted from `inference_endpoint` (default `8080`).
- **FR-013**: `microjail init` MUST write `.workshop/local-inference/sdk.yaml` using `generate_sdk_yaml(config)` when `inference` is not `None`.
- **FR-014**: `microjail init` MUST call `workshop_client.connect(env_name, 'local-inference:llama', 'system:llama', workspace)` after launch when `inference` is not `None`.

### Key Entities

- **`EnvironmentConfig`**: Gains `inference_endpoint: str | None`. Passed to `generate_workshop_yaml`. Never persisted directly.
- **`AgentHarness`**: Literal type extended to `Literal["opencode", "omp"]`.
- **`EnvironmentState`**: Unchanged in structure; CTF now uses it rather than a raw dict.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: `ctf/workshop_config.py` is deleted; `ctf/main.py` has zero local workshop-YAML-generation logic.
- **SC-002**: `ctf/main.py` has zero hand-built state dict construction; state is written via `EnvironmentState.to_json()`.
- **SC-003**: `microjail.config.models.AgentHarness` includes `"omp"` and the full unit test suite passes green.
- **SC-004**: Running `generate_workshop_yaml` with `agent="opencode"` and no inference produces bit-for-bit identical output to the pre-refactor version (no regression for inference-free environments). `opencode+llama-cpp` environments now produce `workshop.yaml` plus `.workshop/local-inference/sdk.yaml` — the project-SDK migration applies to all inference configs.
- **SC-005**: The `test_ctf_workshop_config.py` test file is removed (module deleted); new tests covering the omp/inference-endpoint paths live in the existing `test_config_workshop.py`.
- **SC-006**: `generate_sdk_yaml` with `inference_endpoint='host:9000'` produces YAML with plug `llama` at endpoint `localhost:9000`; with `inference_endpoint=None` defaults to `localhost:8080`.

## Assumptions

- The `omp` agent SDK's Workshop channel is `14/edge`; this is the same value already hardcoded in `ctf/workshop_config.py`.
- microjail migrates from inline plug/slot to the project-SDK pattern proven by CTF. `workshop.yaml` references `project-local-inference`; `.workshop/local-inference/sdk.yaml` holds the plug; `workshop connect` wires them. Validated in production by existing CTF implementation.
- Workshop does NOT auto-connect project-SDK plugs/slots; explicit `workshop connect` is required and is now part of `microjail init`.
- CTF retains its explicit `workshop_client.connect()` call (CTF manages its own temp workspace outside `microjail init`'s lifecycle); the string literals are replaced with `INFERENCE_PLUG_REF`/`INFERENCE_SLOT_REF` constants so the names are no longer duplicated.
- `--inference-url` on `microjail init` is optional; omitting it and specifying `--inference llama-cpp` continues to use `localhost:8080` as today.
- CTF's container-side inference tunnel probe (`_probe_inference_tunnel`) remains in `ctf/main.py` — it is genuinely CTF-specific and has no counterpart in microjail's gate system.
- The CTF still calls `lock_egress`/`unlock_egress` directly rather than `perform_lock`, because it needs to interleave the monitoring loop between lock and unlock, which `perform_lock` does not support. This is not a regression.
